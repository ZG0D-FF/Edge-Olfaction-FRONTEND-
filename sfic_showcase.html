Dual-Tier Decoupled Architecture

Engineered for Thermal & Signal Isolation.

Analog sensor cross-sensitivity and Raspberry Pi thermal throttling are solved by physically decoupling deterministic 10-bit analog acquisition from non-blocking edge wavelet analytics.

Tier 1 · Deterministic MCU

Arduino Uno R3 (ATmega328P)

Dedicated 10-bit Successive Approximation (SAR) ADC continuously polling the 4-channel MOS gas sensor array at 1 Hz (4.88 mV resolution). Frames multi-channel telemetry over 9600-baud UART via a 1 kΩ / 2 kΩ resistor-divider level shifter into 3.3V GPIO.

10-Bit SAR ADC 5V ↔ 3.3V Shifted 0.67–1.0 Hz Polling
Tier 2 · Edge Compute Node

Raspberry Pi 4 Model B

Quad-Core Cortex-A72 edge node executing lock-based asynchronous threading. Offloads 10-second Haar Wavelet (DWT db1) matrix math to a background daemon thread, eliminating main-loop blocking (0.0 ms delay) while logging to local thread-safe CSV storage.
