IEEE 4-Sensor VOC Emission Index at the Edge

Traditional cloud-dependent IoT fails in rural logistics. This Adaptive Hybrid Edge-Olfaction framework uses a 4-channel MQ sensor array with DWT denoising, Kalman/EMA filtering, and Rs-based calibration to predict spoilage in real-time — fully offline on a Raspberry Pi.

The Infrastructure Gap

This section outlines the foundational socio-technical problem addressed by the report. The humid corridors of West Bengal (e.g., Khardaha) present a volatile transit environment for climacteric produce like the Himsagar mango. The interactive comparison below illustrates why traditional cloud-reliant architectures fail, establishing the necessity for an edge-native approach.

The IEEE VEI Risk Engine

The core innovation is a 4-sensor weighted VOC Emission Index using calibrated Rs resistance values. The VEI formula (MQ3×0.55 + MQ135×0.30 + MQ4×0.10 + MQ2×0.05) replaces the old single-sensor Arrhenius model. Interact with the slider below to see the risk calculation.
